# 运行与复现说明

## 1. 前置条件

- Python 3.11 或更高版本。
- 在仓库根目录执行命令。
- 使用 `requirements.txt` 安装依赖。

```powershell
python -m pip install -r requirements.txt
```

## 2. 运行代码

执行以下命令可复现仓库中基准实验的主要结果：

```powershell
python -m src.simulate --runs 10000 --seed 20261115 --deadline 70 --deadline 80 --deadline 90 --output-dir outputs
```

参数说明：

| 参数 | 含义 |
|---|---|
| `--runs` | 蒙特卡洛模拟次数；正式实验使用 10,000。 |
| `--seed` | NumPy 随机种子；相同种子可重现实验。 |
| `--deadline` | 截止日期，单位为工作日；可重复指定多个情景。 |
| `--output-dir` | 结果输出路径。 |

## 3. 运行测试

```powershell
python -m pytest -q
```

测试覆盖 PERT 期望工期、常数工期抽样、并行任务的网络计划计算和循环依赖拒绝。

在 `seed=20261115`、`runs=10000`、截止日期为 70、80、90 工作日时，主要输出应与下表一致；展示数值已四舍五入，完整精度以 `outputs/` 内 CSV 为准。

## 5. 输出文件说明

- `cpm_schedule.csv`：CPM 工期、ES、EF、LS、LF、总时差和 CPM 关键任务。
- `simulation_runs.csv`：10,000 次模拟的任务抽样工期与项目总工期。
- `project_summary.csv`：项目总工期统计量。
- `deadline_probabilities.csv`：截止日期情景及按期概率。
- `task_sensitivity.csv`：Pearson、Spearman 和关键路径出现频率。
- `task_duration_summary.csv`：任务抽样工期统计量。
- `cpm_vs_monte_carlo.csv`、`tornado_analysis.csv`：方法和单因素影响对比表。
- PNG 文件：任务网络、箱线图、直方图、CDF、截止日期概率、敏感度、关键路径频率、龙卷风与 CPM 对比图。
